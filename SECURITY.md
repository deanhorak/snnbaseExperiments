# Security policy

## Supported versions

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository. If it
is unavailable, contact the repository owner privately through the contact method on their GitHub
profile.

Include affected revisions, impact, reproduction details, and any proposed mitigation. Do not
include real credentials or sensitive datasets. Allow reasonable time for investigation before
public disclosure.
